StereoMap 4.3.0 更新亮点

  • 可视化：
    • 全新 Visual Explore 可视化！新的用户界面提供了更好的视觉效果，并优化了工作区布局，助力更高效的数据分析。
    • 新可视化界面布局划分为：操作模式栏、图层展示面板、画布区和数据图表区。
      • 操作模式栏 包括 Feature（特征）、Group（分组）、Selection（筛选），用于决定数据点的展示颜色或组合方式。新增的Selection功能支持根据 Group 或 Feature 进行坐标 bin 的过滤，过滤后保留的 bins可以新建并保存为 group。
      • 图层展示面板 包括 Bin layer、Cell layer、Image layer。您可以自由叠加图层，并调节图层的透明度，实现空间特征表达矩阵与图像的协同展示。
      • 画布区 是展示数据的核心区域，用于呈现完整的数据集。
      • 数据图表区 则用于展示表格或统计图表，帮助您更直观的分析和解读数据。
    • 新增“Projection”功能，可展示一个或多个芯片数据的不同空间投影方式，并支持细胞的 UMAP 图展示。
    • 新增”Split View“功能， 支持根据选定标签或类群，将 bins/cells 分割至多个独立子图进行可视化。
    • 全新的“Annotation Shape”功能允许您在每次数据集分析时创建并临时存储一系列套索形状。这使得您能够在指定区域内，以不同分辨率（网格大小）反复提取点的坐标或特征空间表达矩阵。此外，这些套索形状可以导出为 .geojson 文件，便于在下次分析中重新导入使用。
    • 更加便捷的区域选择与导出。使用套索工具选择区域后，选中的点或细胞可以保存到 Group 中。您可以从 Group 中导出点的坐标为 .csv 文件，或者导出矩阵为 .gef/.gem/.h5ad 格式，方便后续分析。
    • 新增本地聚类分析和差异分析功能（需获取本地资源），无需依赖SAW（在资源满足的情况下）。这使您可以在本地环境中独立完成复杂的数据分析任务，进一步提升了数据处理的灵活性和自主性。
    • 聚类图的默认配色调整，以更好地适配浅色 UI 模式，提升视觉体验。
    • 可视化画布截图功能升级，新增透明背景和自定义颜色背景下载功能。
    • 多窗口联动展示：相同binsize时，可基于 Group 模式中选择的标签/类群。或基于 Feature 模式中选择的单基因/多基因，对 bins/cells 进行联动。
    • 多片分析： 支持导入 SAW aggr 结果文件 (.stereo) 展示结果。新增Across multiple sample表单填写和导出用于差异分析的CSV，可在 SAW reanalyze diffExp 中分析选定区域内不同切片间的表达差异。
  • Image Processing图像处理：
    • Step 2: 支持显示完整芯片矩阵。可调整矩阵Bin size。
  • Tools：
    • 发布新工具：图像对齐-Manual Alignment！您可以通过标记点来对齐多幅图像。

系统要求

最低配置
Windows
  • Windows 10或更高的版本（64 位）
  • 内存：16 GB(仅小工具-QC支持最小8GB)
  • 强烈建议使用 SSD 固态硬盘
  • 建议缩放设置为 100%
MacOS
  • 仅适配了 M 系列的芯片
  • MacOS 12.5.1 (Monterey) 或更高的版本*
  • 内存：16 GB
  • 强烈建议使用 SSD 固态硬盘
  • 建议使用默认的设置

*为确保研究数据的安全性和软件的稳定性，我们提高了最低系统要求，详情请参阅 Apple 安全更新页面。

性能说明

  • 如果您要处理超大规模数据（如超过 10 万个细胞或 bin 数据），我们建议使用 32GB 及以上内存和四核处理器，以确保软件顺畅运行。
  • 如果您使用外部存储设备（比如移动硬盘）时，由于读写速度较慢或可能意外断开，运行速度可能变慢，甚至导致软件崩溃。

软件安装

下载.exe文件，双击可执行文件开始安装。

如果在安装的过程中遇到如下提示，您可以点击“打开”，将其添加到信任中。

选择安装路径，默认为"D:\StereoMap"，可根据需要修改目标文件夹。点击 Install 开始安装。

首次安装或者在线更新，请确保您的安装目录必须满足至少 20GB 的可用磁盘空间。

请确保安装路径中未包含其它特殊字符或者符号。当前支持的字符包括：空格、下划线、字母A~Z和数字0~9。

安装完成后，点击 Finish 即可。

相关软件（SAW）兼容

  • SAW >= v8.0 （历史版本的适配兼容信息）。
  • 请使用最新的 Image QC 重新QC，生成 TAR(.tar.gz)图像文件。

设置

在线更新

点击右上角的设置，选择 About ，联网状态下可以手动检查版本信息，如果有新版本发布，您可以选择下载并安装新的软件包。

您也可以勾选软件开机时自动检查最新版本的选项，程序会自动检测是否有新版本的更新。

保存

设置每个模块输出文件的路径，默认是您的安装目录，您也可以根据需求更改。
