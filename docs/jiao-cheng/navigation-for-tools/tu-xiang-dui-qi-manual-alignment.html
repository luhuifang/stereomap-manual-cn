图像对齐-Manual Alignment

进入手动对齐功能

Step 1: 上传图像

在此步骤中，您需要上传参考图像和对齐图像以进行处理。

  1. 设置一个参考图像

  2. 支持格式：TIFF、Image TAR.GZ 或 .stereo 文件。

  • 您可以点击 替换当前参考图像。

  1. 添加对齐图像

  2. 支持格式：TIFF、Image TAR.GZ 或 .stereo 文件。

  • 如需添加更多对齐图像，请点击 按钮。

  • 注意：

    • 参考图像决定样本编号（SN）。
    • 您可以通过关闭对应标签页来移除指定图像。

  • 配置图像信息

输入文件格式染色类型: ssDNA/DAPI/H&E染色类型: IF
TIFF手动输入手动输入
.stereo/compressed Image TAR.GZ基于文件元数据的自动检测

基于文件元数据的自动检测。

如果您已在参考图像中上传了 DAPI 图像，则可以在对齐图像中关闭重复的 DAPI 图像选项卡。

Step 2: 调整方向

使用旋转或翻转工具粗略地将图像与参考图像对齐。

如果无法在参考图像和对齐图像之间找到共同特征，请联系样本制备人员。

  • 您可以使用这些图标更改方向：
    • 旋转 90°
    • 水平翻转
    • 垂直翻转
  • 请确保每张图像大致与参考图像方向一致，没有发生镜像或 90° 旋转。
  • 点击 “Next” 确认更改。

Step 3: 标记关键点

在参考图像和对齐图像中标记对应的特征点。

  • 阶段 1: 启用同步缩放 (前3对点)

    • 放大到细胞级别，标记 3 对对应特征点。
    • 标记完 3 个有效点对后，软件会自动触发同步缩放。此后在参考图像中的缩放/平移操作将同步至所有对齐图像。

  • 阶段 2: 完成标记

    • 继续标记另外 3 对特征点，以激活 “Next” 按钮。
    • 如有需要，可添加更多点对。若需更精确对齐，建议标记 25–30 个点。无上限限制。完成后请点击 “Next” 确认。

DAPI + mIF 对齐技巧

由于 DAPI+mIF 染色特性，基于细胞形态定位特征点较困难。如果您的 DAPI + mIF 成像在同一芯片上，可通过调节亮度、归一化和对比度来识别芯片轮廓。

Step 4: 检查 & 微调

首先检查对齐结果。如有偏差，可通过移动、缩放或旋转微调。若有多张图像，请逐一审查并单独调整。

  • 调整视觉属性以提升叠加可视性。注意：这些设置导出时不会被保存。
    • 归一化
    • 对比度
    • 亮度
    • 不透明度
    • 饱和度（彩图可调节）
    • 伪彩 （灰度图可调节）

您还可以查看对齐图像的变换数值（如旋转角度、缩放比例等）。

Step5: 导出

导出对齐后的图像，用于后续分析或可视化。

  • 导出为 TIFF 格式

命名规则：\_\.tif

如果您输入的是 .stereo 或压缩的 TAR.GZ 文件，且它们已与矩阵配准过，软件会自动翻转它们。

  • 导出为 RPI 格式

可在 Visual Explore 中查看 RPI 文件。了解更多关于 RPI 格式的信息，请参阅 可视化输入文件。
