可视化指南

可视化入口

从 StereoMap 启动页的 Visual Explore 进入可视化。

导入数据

打开 StereMap 软件的 Visual Explore 模块，选择 .stereo 文件。 (可以参考可视化输入文件获取更多信息)。

若要切换到其他数据集，只需点击左上角 Logo 并选择 “Open New File”。这样即可加载新数据集并开始新的分析。

可视化界面

数据加载完成，您将看到可视化模块的界面布局。

您还可以点击 折叠最左侧的侧边栏，以最大化您的工作区域，让你有更多的空间专注于分析。

样本信息

点击 ，您将看到样本的基本数据信息。Dataset Info 用于展示当前数据集概览，帮助你快速了解其来源和关键统计信息。该部分分为两块：Analysis 分析结果 和 Statistics 统计信息。

以上信息需要在打开.stereo文件后方可查看

  • Analysis 分析结果： 包括样本唯一标识、数据分析流程版本、试剂盒版本、测序方式、 样本类型、组织类型和软件版本。

  • Statistics 统计信息：从"bin"（空间位置）和"cell"（细胞）两个维度展示基因类型、细胞数量和 MID 数量。

    • 如果你的数据来自 Stereo-CITE，或 Stereo-seq N FFPE with microbiome analysis，则会看到 多组学数据。你可在 Statistics 中切换不同组学查看对应统计结果。

    • 如果 SAW 分析未使用图像数据，你可以切换到 All bins 选项查看整张芯片的空间矩阵统计。

    • 如果你的数据来自 SAW aggr 流程，你可以查看多个切片的信息。

展示模式

提供三种数据可视化方式，分别适用于不同分析需求：

  • Feature 模式：根据所选基因、蛋白或微生物的表达水平（MID count）为 bins/cells 着色。
  • Group 模式：根据聚类结果、细胞注释或手动分组为 bins/cells 着色，用于显示不同分类。
  • Selection 模式：可通过公式筛选特定 bins/cells，并保存为新分组用于后续分析。

在不同展示模式之间切换时，工作区中的数据展示会同步更新。

Feature

Feature 模式可用于探索数据集中指定基因、蛋白或微生物的表达模式，展示这些特征在组织中的表达与分布。

Feature 列表类型：

  • SAW 生成列表：由 SAW 流程自动生成，按组学类型展示 全部检测到的 feature 及其统计信息。若数据包含 多组学，会出现多个列表。由于 bin 覆盖范围不同，Bin 与 Cell 列表内容可能略有差异。Bin 的特征列表（如 bin10、bin20）包含 feature name、MID count 和 E10 score（空间富集度）；而 Cell 的特征列表 显示的是表达该特征的 细胞数量，而非 E10 分数。E10 分数越高，表示该特征在空间上越聚集。
  • 自定义列表：这里显示你手动选择的feature，与 SAW 生成列表分开管理，方便快速访问。若自定义列表包含不同组学特征，可切换组学标签查看对应热图。

选择特征并创建 Feature 列表

  • 快速查看：点击某个特征可在工作区显示其热图。按住 Ctrl 可多选 feature（支持跨行选择），并查看它们的 组合热图。如需查看特征在空间上的共表达，可参考基因共表达分析。

  • 创建 Feature 列表：有三种方式创建并向自定义列表添加 feature：

    1. 新建列表或上传列表：点击底部 可创建空白自定义列表，或点击 Upload 导入已有列表。

    2. 从 SAW 生成列表添加：将鼠标悬停在 SAW 生成列表中的某个feature上，点击 图标即可加入自定义列表。若已按住 ctrl 选中多个特征，点击 并选择 “+ Add the selected to feature list”，即可一次性全部添加。

    3. 从搜索栏添加：search 支持 不区分大小写。使用复选框 可多选特征，然后点击 Feature 标题旁的 按钮，将其批量加入自定义列表。

  • 下载 Feature 列表：可点击 下载自定义特征列表，便于后续重新导入或其他用途。

Group

Group 模式 用于探索数据中的 spot 与 cell 分类。cluster 指一组具有相似特征的 bins 或 cells；group 则是这些 clusters 的集合。该模式可帮助你组织并可视化数据中的不同分类结果。

Group 类型

  • SAW 生成分组：展示由 SAW 流程（SAW count、SAW realign）在不同 bin size 下计算得到的 Leiden 聚类结果。由于聚类结果依赖 bin size，如果看不到 cluster，请尝试在 Bin Layer 中调整 bin size，或启用 Cell Layer。点击 （悬停在 cluster 上会出现），可修改该 cluster 的颜色与名称。
  • 自定义分组：由你手动创建，可按分析需求定义 clusters。可修改 cluster 的颜色与名称，也可修改对应自定义 group 的名称。
  • 重聚类分组：展示在 StereoMap 中计算得到的重聚类结果。

创建 Group 并分配 Cluster

  1. 新建或上传 Group：点击 New Group 按钮创建空白 Group，然后手动添加 clusters 进行分类。也可使用 Upload 导入包含坐标分类或细胞注释信息的 .csv 文件，系统会根据文件内容自动生成对应 Group 和 clusters。
  2. 使用 Lasso 工具：在 鼠标工具 中选择 Lasso，并在感兴趣区域外 绘制边界。选区内的 bins 或 cells 可保存为一个 cluster，并添加到指定的自定义 group。
  3. 使用 Selection 模式：切换到 Selection 模式，按 MID 数值或聚类/分组条件筛选 bins 或 cells。筛选结果可保存为 cluster，并存入指定的自定义 group。

下载 Group 与矩阵

对于分组，你可以按不同格式下载数据。每种格式都面向不同需求，无论是空间 bin 聚类还是详细的表达矩阵都可覆盖。

  • CSV：逗号分隔文本文件，包含 x/y 坐标和 bin 聚类信息。你也可以下载用于 差异表达分析 的 .csv，其中包含额外的 cluster 比较信息。该选项尤其适合大数据集，可将分组信息传递给 SAW 在服务器端分析。

  • GEF：HDF5 格式空间特征矩阵，包含 feature ID、x/y 坐标、MID count 等。.gef 文件可保存 多个 bin size 的矩阵，下载时会提示你选择所需分辨率。

  • GEM：TSV 格式矩阵，包含 feature ID、x/y 坐标、MID count 等。每个 .gem 文件仅包含 单一 bin size 的矩阵。
  • H5AD： H5AD 格式文件，包含带注释的数据矩阵、空间坐标、元数据。
  • H5MU：H5MU 格式文件，包含多样本或多切片的特征表达、空间坐标和元数据。

聚类与差异表达分析

StereoMap 4.3 现已支持本地 Clustering 和 Differential Expression Analysis，无需依赖外部流程即可进行更高级的本地数据处理。

在 Group 模式下，你可以选择感兴趣的 bins/cells 进行重聚类，或执行差异表达分析，以深入解析特定亚群。

空间重聚类

在 Group 中选中目标 clusters 后点击 Clustering 按钮，系统会将所选 bins 或 cells 合并用于分析。在弹窗中可选择合适组学（如需要）、调整聚类参数，并使用本地计算资源运行分析。

若处理的 spots 数量非常大，建议使用 SAW 流程以确保有足够计算资源。

自定义 cluster 的差异表达分析

你可以对已选 clusters 执行差异表达分析。在 Group 模式中选中待分析 clusters 后，点击 Differential Expression Analysis 按钮。在弹窗中选择分析模式（ Label vs. Label 或 Label vs. Others ）。结果会显示在右下角 Data Panel。更多信息见 差异分析。

Selection

Selection 模式允许你根据特征 MID 计数或 cluster 隶属关系筛选 bins 或 cells。一条规则只能包含一种过滤逻辑（AND/OR）。要同时使用AND和OR，请点击 New ruleset 并定义规则之间的逻辑关系。

点击 Save 到自定义标签和组。您可以在Group模式下查看已保存的结果。

投影与图层

投影 Projection

投影 Projection 可让你选择空间数据的可视化方式：原始空间布局（Spatial）或 UMAP 表示。

默认的 Spatial 视图按真实物理坐标显示 bins/cells；不同 UMAP 选项（如 UMAP-bin、UMAP-cell 等）则提供降维表示。这种灵活性有助于从不同角度探索空间关系与聚类模式。

窗口间联动分析

如果你想在单独窗口中查看某个 Projection，只需点击每个 Projection 右侧的 。打开后的窗口可进行 窗口间联动分析，通过在不同组学间选择 clusters 或相关 features 实现关联。关于 基于 cluster 的联动分析，请参考 微生物宿主分析；关于 多组学特征联动，请参考 蛋白与其对应标记基因的空间分布。

图层 Layers

Layer 菜单控制工作区数据展示方式，提供三个相互独立的图层：bin layer、cell layer 和 image layer。

  • Bin Layer：以方形 bin 的形式可视化组织区域，适合识别组织尺度的空间模式，并分析区域生物标志物表达。
  • Cell Layer：以单细胞分辨率展示空间数据，适合探索细胞层面的空间关系。
  • Image Layer：显示与矩阵同向的显微参考图像（HE/ssDNA 等），用于将分析结果与组织形态对应起来。

可见性控制

  • 点击任意图层名称旁的 .svg>) / 可切换显示状态；多个图层可同时可见。

图层激活控制

每个图层都可独立调整，类似 Photoshop 或常见图形编辑软件：你的编辑只会作用于当前激活图层。

  • 图层激活 ≠ 图层可见：仅可编辑已显示图层。
  • 黄色高亮 的图层会接收所有编辑与调整。
  • 点击图层名称（而非 .svg>)) 或下拉区域，即可切换可编辑图层。

图层专属调节：

每个可视化图层都提供了适配其数据类型的 专属控制项。

Bin Layer Cell Layer Image Layer

Most adjustments are standard—just note some key settings:

  • All bins / Bins under tissue：
    • 包含来自 SAW count 或 SAW realign 的 .stereo 数据。
    • 若 .stereo 文件不含图像信息，你可能会在图层顶部看到 All bins。可切换到该标签重新进行组织区域套索。
  • View bin/cell as:
    • 在 Heatmap 与 Cluster 显示方式间切换，可在定量梯度和分类分组视图间转换，并自动更新 Display mode。
    • Multi-colored 模式仅在显示 自定义 feature 列表 时可用。该模式下可为每个 feature 分配独立颜色，便于比较它们在工作区中的空间位置。
  • Color range：默认范围为 0 到当前所选 bin size/cell 的最高 MID count。你可自定义范围，以更突出特定表达区间内的 bins。
  • Bin size：更改 Bin size 会同时更新工作区显示和聚类结果。若该 bin size 下不存在分组，bins 将以统一默认颜色显示。Cell Layer 下不可用。
  • Style of bin：仅适用于 Spatial projection。用于设置组织区域覆盖层的显示样式（独立统一颜色层），不会改变 bin 的方形形状。
  • Style of cell：仅适用于 Spatial projection。可设置细胞显示为仅边界、填充或二者同时显示。

  • Image layer 的设置略有不同，可让你叠加多张图像共同查看。点击 即可切换其可见性。

Split View

Split View 支持按 label 或 cluster 并排比较数据分布，适用于观察不同生物学条件、细胞类型或空间区域间的表达差异。

点击 Split 启用。随后会出现下拉列表，列出当前激活图层及其所选 bin size 下的所有可用 groups

选择某个 group 后，当前投影（UMAP 或 Spatial）会按该 group 中各 label/cluster 拆分为多个子图。若部分 spots 未分配到任何 label/cluster，系统会在最后自动添加一个未标注子图。

工作区与工具

工作区

工作区 是核心交互区域，主要承担 3 项功能：

  • 显示所有叠加图层（Bin layer、Cell layer、Image layer），支持多模态数据探索。
  • 通过浮动工具（鼠标工具、缩放控制 等）直接操作数据，并通过控制面板（展示模式、投影与图层）动态调整视图。
  • 集成小地图、颜色条、比例尺等辅助元素，确保空间定位精准、数据解读准确。

缩放控制

  • 自动适配视图：将视图居中并自动调整缩放，以显示整个组织区域。
  • 通过拖动滑块或点击图标进行缩放。

设置

Settings 用于控制工作区浮动元素的可见性，包括比例尺 scale bar、颜色条 color bar、文字提示 Tooltip、小地图 minimap 和 参考轨迹线模板 reference trackline template。

Reference trackline template 可用于检查显微镜采集 trackline 是否与基于测序空间特征表达矩阵得到的参考 trackline 正确叠加。更多信息见 检查图像的配准。

导出

点击 可将当前工作区视图保存为图片（PNG）。可选择普通 PNG、快速截图（按屏幕分辨率截取当前可见区域），或 HD PNG（高分辨率高清图像）以获得更细节的可视化。

你可按需求自定义背景颜色（如透明或从调色板选择）。点击 Export 后会打开文件系统，供你选择保存路径与文件名。该功能可灵活满足报告、演示或后续分析的图像输出需求。

数据面板

数据面板 Data Panel 会根据当前选中的 group 和空间 bin size，动态显示 Differential Expression（DE）Analysis 结果。

  • 点击表格中 feature 名旁的 ，可将该特征保存到自定义 feature 列表，便于后续批量管理与下游分析。
  • 点击 可将表格导出为 CSV。
  • 若数据来自 SAW aggr，并且你在跨切片公共 cluster 的差异分析中指定了实验条件（--group-by-deg），数据面板会显示对应的差异表达（DE）结果。你可通过区域下拉菜单在 clusters 间切换，并查看所选实验条件下的 DE 结果。
